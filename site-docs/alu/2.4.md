# § 2.4. Comparison and Selection

`ZeroDetect<W>` reduces a word to a predicate. `CompareSelect<W>` consumes a subtraction result and its flags to select predicates or min/max operands. The complete ALU shares its subtraction hardware between arithmetic and comparison.

| Component | Description | Structural | Behavioral |
| --- | --- | :---: | :---: |
| `ZeroDetect<W>` | One-bit all-zero predicate | Yes | Yes |
| `CompareSelect<W>` | Equality/less-than predicates and signed/unsigned min/max | Yes | Yes |

W is **8, 16 or 32**. The fidelity columns hold at every width: each unit has a structural and a compact form at 8, 16 and 32 bits. The C++ references take W as a template parameter. [Construction and selection](2.6.md#construction-and-selection) describes construction.

## 2.4.1. `ZeroDetect<W>`

### IO pins

| Pin | Direction | Width | Description |
| --- | --- | ---: | --- |
| `A` | Input | W | Word to inspect |
| `ZERO` | Output | 1 | High when all W bits are zero |

### Behavior

ZERO is NOT of the OR reduction of A[0] through A[W−1]. It is a one-bit predicate with no signed interpretation, clock or state.

#### C++ example

This binary reference is parameterized by W = 8, 16 or 32. Inputs must fit their documented pin widths. It omits propagation delays and X/Z values.

```cpp
#include <cstdint>

template<unsigned W>
bool zero_detect_ref(std::uint32_t a) {
    return a == 0;
}
```

#### Unknown inputs

A known one anywhere makes ZERO=0. All known zeros make ZERO=1. With no known one, any X/Z makes ZERO=X. The output never drives Z.

### Implementation

#### Structural implementation

A splitter feeds an OR reduction and a final NOT. The eight-bit tree has seven OR gates in three levels; larger widths use the width-aware reduction recipe. The same component serves equality detection and the complete ALU's result-zero flag.

#### Behavioral implementation

The compact form computes the same OR reduction with four-state values, so its output matches the gates for every input. It exists at W = 8 and 32 (the 16-bit detector is structural) and runs on delays proven on the gates.

## 2.4.2. `CompareSelect<W>`

### IO pins

| Pin | Direction | Width | Description |
| --- | --- | ---: | --- |
| `A`, `B` | Input | W each | Original operands for min/max |
| `DIFF` | Input | W | Wrapped A−B |
| `CARRY_IN` | Input | 1 | Subtraction carry-out; high means no borrow |
| `OVERFLOW_IN` | Input | 1 | Subtraction signed overflow |
| `OP` | Input | 3 | Local comparison selector |
| `OUT` | Output | W | Zero/one predicate or selected original operand |

### Behavior

The caller supplies consistent subtraction outputs. Decisions are `E = [DIFF == 0]`, `Lu = NOT CARRY_IN` and `Ls = DIFF[W−1] XOR OVERFLOW_IN`.

| Local OP | Operation | OUT | ALU OP |
| ---: | --- | --- | ---: |
| 0 | EQ | E, zero-extended | 21 |
| 1 | SLTU | Lu, zero-extended | 22 |
| 2 | SLT | Ls, zero-extended | 23 |
| 3 | MINU | A if Lu, otherwise B | 24 |
| 4 | MAXU | B if Lu, otherwise A | 25 |
| 5 | MINS | A if Ls, otherwise B | 26 |
| 6 | MAXS | B if Ls, otherwise A | 27 |
| 7 | Reserved | Zero | No comparison operation |

The unit has no subtractor or flags. CARRY_IN is the subtraction's output, not an input carry operand. Min/max return original bit patterns. The extended complete ALU clears carry/overflow for these operations, although subtraction flags are used internally.

#### C++ example

This binary reference is parameterized by W = 8, 16 or 32. Inputs must fit their documented pin widths. It omits propagation delays and X/Z values.

```cpp
template<unsigned W>
std::uint32_t compare_select_ref(
    std::uint32_t a, std::uint32_t b, std::uint32_t diff,
    bool carry_in, bool overflow_in, std::uint32_t op) {
    const bool equal = zero_detect_ref<W>(diff);
    const bool unsigned_lt = !carry_in;
    const bool signed_lt = ((diff & WordReference<W>::sign) != 0) != overflow_in;
    switch (op) {
    case 0: return static_cast<std::uint32_t>(equal);
    case 1: return static_cast<std::uint32_t>(unsigned_lt);
    case 2: return static_cast<std::uint32_t>(signed_lt);
    case 3: return unsigned_lt ? a : b;
    case 4: return unsigned_lt ? b : a;
    case 5: return signed_lt ? a : b;
    case 6: return signed_lt ? b : a;
    default: return 0;
    }
}
```

#### Unknown inputs

Each predicate uses only its declared subtraction signals. Known controlling bits can mask unknowns. Operand selections follow gate-built muxes rather than an optimistic merge; high impedance through logic becomes X. Known reserved OP masks OUT to zero.

### Implementation

#### Structural implementation

One `ZeroDetect<W>`, no-borrow inversion and sign/overflow XOR produce E/Lu/Ls. Four word muxes `MINU`, `MAXU`, `MINS` and `MAXS` (`Mux<2,W>`, one 2:1 mux per bit) choose the unsigned and signed min/max words. The predicates become words with the flag in bit 0 (wiring only), and one `Mux<8,W>` (`RESULT`, an eight-way mux per bit) chooses predicates, operands or reserved zero. The shared subtraction remains in the parent arithmetic path.

#### Behavioral implementation

The compact form, available at W = 8, 16 and 32, computes the settled outputs of these gates in one step. It keeps the gates' Boolean factoring, so X and Z inputs give the same outputs as the structural circuit, and it runs on delays proven on that circuit ([delay model](../basic/1.2.md)).
