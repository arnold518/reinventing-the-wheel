# § 2.2. Logic Operations

`LogicUnit<W>` with `Operations::Extended` selects seven bitwise operations. `Operations::IntegerDatapath` exposes three simultaneous outputs through a different interface, specified in [2.7](2.7.md#272-logicunitw). These operation contracts are independent of W.

| Component | Description | Structural | Behavioral |
| --- | --- | :---: | :---: |
| `LogicUnit<W>` | Selected AND/OR/XOR/NOT/NAND/NOR/XNOR result | Yes | Yes |

W is **8, 16 or 32**. The behavioral column describes the recorded eight-bit ripple configuration; other word widths/topologies use structural circuits unless their catalog family provides a matching behavioral factory. The binary C++ references take W as a parameter; the tables record their stated concrete eight-bit configuration. [Configuration and family selection](../components/word-components.md) specifies construction.

## 2.2.1. `LogicUnit<W>`

### IO pins

| Pin | Direction | Width | Description |
| --- | --- | ---: | --- |
| `A` | Input | W | First operand; the only operand used by NOT |
| `B` | Input | W | Second operand |
| `OP` | Input | 3 | Local operation selector |
| `OUT` | Output | W | Selected bitwise result |

### Behavior

Every output bit depends on the same-position operand bits. Complements are limited to W bits; there is no inter-bit carry.

| Local OP | Operation | OUT | Complete extended OP |
| ---: | --- | --- | ---: |
| 0 | AND | A AND B | 8 |
| 1 | OR | A OR B | 9 |
| 2 | XOR | A XOR B | 10 |
| 3 | NOT | W-bit complement of A; B ignored | 11 |
| 4 | NAND | W-bit complement of A AND B | 12 |
| 5 | NOR | W-bit complement of A OR B | 13 |
| 6 | XNOR | W-bit complement of A XOR B | 14 |
| 7 | Reserved | Zero | 15, reserved |

The unit has no carry, flags or invalid-operation output. The complete ALU derives flags after result selection.

#### C++ example

This binary reference is parameterized by W = 8, 16 or 32. Inputs must fit their documented pin widths. It omits propagation delays and X/Z values.

```cpp
#include <cstdint>

template<unsigned W>
std::uint32_t logic_ref(
    std::uint32_t a, std::uint32_t b, std::uint32_t op) {
    const std::uint64_t x = a, y = b;
    std::uint64_t result;
    switch (op) {
    case 0: result = x & y; break;
    case 1: result = x | y; break;
    case 2: result = x ^ y; break;
    case 3: result = ~x; break;
    case 4: result = ~(x & y); break;
    case 5: result = ~(x | y); break;
    case 6: result = ~(x ^ y); break;
    default: result = 0; break;
    }
    return static_cast<std::uint32_t>(result & WordReference<W>::mask);
}
```

#### Unknown inputs

AND with zero and OR with one mask unknown inputs. XOR and inversion produce X when their relevant input is X/Z. NOT ignores B. Known reserved OP returns zero. Unknown OP follows the mux equations, including their conservative four-state behavior.

### Implementation

#### Structural implementation

Two splitters feed W AND, W OR and W XOR gates. Four NOT gates per bit produce the inverted candidates. W scalar eight-way muxes select the result; a constant zero supplies the reserved input. One joiner assembles OUT. The circuit is identical in construction rule at W=8, 16 and 32.

#### Behavioral implementation

The settled-value rules are parameterized by W and addition topology in `ExtendedALUValueModel<W, Topology>` (`WordALUValueModel.hpp`). They use the same four-state gates, masks, carry construction and movement stages as the structural circuit. Word loops use W, the sign is bit W−1, and the shifter has log₂(W) stages. Operation codes and local selector sizes are control widths and remain independent of W.

A catalog behavioral factory is available only for its verified configuration. The eight-bit ripple adapter uses these shared rules with its characterized delay table; other configurations on this page remain structural. The value model alone does not supply timing or enable compact fidelity. `ALUWidthContractTest` compares both topologies at 8/16/32 bits against the gates and an independent binary reference; `ExtendedALUFidelityContractTest` retains the compact-fidelity checks for those configurations.
