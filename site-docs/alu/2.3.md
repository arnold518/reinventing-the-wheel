# § 2.3. Shifts and Rotations

`BarrelShifter<W>` with `Operations::Extended` produces shifts, rotations and the last displaced bit. It is combinational: distance is selected by a mux network, with no repeated clocked shifting. The [integer contract](2.7.md#273-barrelshifterw) supplies shift-only controls and has no carry output.

| Component | Description | Structural | Behavioral |
| --- | --- | :---: | :---: |
| `BarrelShifter<W>` | Variable-distance shifts/rotations with carry | Yes | Yes |

W is **8, 16 or 32**. The behavioral column describes the recorded eight-bit ripple configuration; other word widths/topologies use structural circuits unless their catalog family provides a matching behavioral factory. The binary C++ references take W as a parameter; the tables record their stated concrete eight-bit configuration. [Configuration and family selection](../components/word-components.md) specifies construction.

## 2.3.1. `BarrelShifter<W>`

### IO pins

| Pin | Direction | Width | Description |
| --- | --- | ---: | --- |
| `A` | Input | W | Word to shift or rotate |
| `B` | Input | W | Distance from the low log₂(W) bits; upper bits ignored |
| `OP` | Input | 3 | Local shift/rotation selector |
| `C_IN` | Input | 1 | Carry returned for valid distance zero |
| `OUT` | Output | W | Shifted or rotated word |
| `CARRY` | Output | 1 | Last displaced bit, or C_IN for distance zero |

### Behavior

The effective distance is `n = B & (W−1)`, ranging from 0 to W−1.

| Local OP | Operation | Movement/fill | Complete extended OP |
| ---: | --- | --- | ---: |
| 0 | SLL | Left, zero fill | 16 |
| 1 | SRL | Right, zero fill | 17 |
| 2 | SRA | Right, fill with A[W−1] | 18 |
| 3 | ROL | Left, wrap displaced bits | 19 |
| 4 | ROR | Right, wrap displaced bits | 20 |
| 5–7 | Reserved | OUT=0, CARRY=0 | Other ALU groups |

For valid n=0, OUT=A and CARRY=C_IN. For n>0, SLL/ROL carry is original A[W−n]; SRL/SRA/ROR carry is original A[n−1]. C_IN never fills OUT and is ignored at nonzero distance. Rotation covers exactly W bits. Arithmetic right shift fills the sign and rounds negative signed values toward negative infinity.

#### C++ example

This binary reference is parameterized by W = 8, 16 or 32. Inputs must fit their documented pin widths. It omits propagation delays and X/Z values.

```cpp
#include <cstdint>

template<unsigned W>
struct ShiftResult {
    std::uint32_t OUT;
    bool CARRY;
};

template<unsigned W>
ShiftResult<W> shift_ref(
    std::uint32_t a, std::uint32_t b, std::uint32_t op, bool c_in) {
    if (op > 4) return {0, false};
    const unsigned n = unsigned(b) & (W - 1);
    if (n == 0) return {a, c_in};

    const std::uint64_t x = a;
    std::uint64_t result = 0;
    switch (op) {
    case 0: result = x << n; break;                     // SLL
    case 1: result = x >> n; break;                     // SRL
    case 2:                                           // SRA
        result = (x >> n) | ((x & WordReference<W>::sign) ? (WordReference<W>::mask << (W - n)) : 0u);
        break;
    case 3: result = (x << n) | (x >> (W - n)); break;  // ROL
    case 4: result = (x >> n) | (x << (W - n)); break;  // ROR
    }
    const unsigned carry_bit = (op == 0 || op == 3) ? W - n : n - 1;
    return {
        static_cast<std::uint32_t>(result & WordReference<W>::mask),
        ((x >> carry_bit) & 1u) != 0,
    };
}
```

#### Unknown inputs

Unused upper B bits do not affect the circuit. Unknown C_IN is isolated at nonzero distance; at distance zero, X/Z carry produces X through the gates. Relevant unknown controls follow mux logic, while known zero-fill positions can remain determined. Reserved local codes mask both outputs.

### Implementation

#### Structural implementation

Input/output reversal muxes share one rightward network between directions. There are log₂(W) optional stages, at distances 1, 2, 4, …, W/2. Each stage selects data and a displaced carry bit. Fill selection supplies zero, the sign or wrapped data. Carry starts at C_IN; it survives only when every distance stage is disabled. Reserved-operation gates mask the final word and carry.

#### Behavioral implementation

The settled-value rules are parameterized by W and addition topology in `ExtendedALUValueModel<W, Topology>` (`WordALUValueModel.hpp`). They use the same four-state gates, masks, carry construction and movement stages as the structural circuit. Word loops use W, the sign is bit W−1, and the shifter has log₂(W) stages. Operation codes and local selector sizes are control widths and remain independent of W.

A catalog behavioral factory is available only for its verified configuration. The eight-bit ripple adapter uses these shared rules with its characterized delay table; other configurations on this page remain structural. The value model alone does not supply timing or enable compact fidelity. `ALUWidthContractTest` compares both topologies at 8/16/32 bits against the gates and an independent binary reference; `ExtendedALUFidelityContractTest` retains the compact-fidelity checks for those configurations.
