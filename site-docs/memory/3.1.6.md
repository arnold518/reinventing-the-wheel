# § 3.1.6. Scalable Memory Container

`MemoryContainer` provides a scalable behavioral memory endpoint for the five storage technologies introduced in this section. It is not a sixth physical technology. Internally, it is the compact equivalent of a [controller plus native device](3.3.md), exposed through the [shared transaction interface](3.2.md). Sharing a port does not make the storage rules identical.

| Component | Description | Structural | Behavioral |
| --- | --- | :---: | :---: |
| `MemoryContainer<W,Model>` | Configurable-capacity transaction endpoint with separate FF, SRAM, DRAM, ROM, or NOR-flash behavior | No | Yes |

Its lower-level counterpart is `MemoryEndpoint<T,W>` from 3.3. The container does not pretend to expose raw cell or native device pins. Select the assembled endpoint to inspect registers, device controls, rows and columns; select its behavioral implementation to replace that whole boundary with one container.

## Configuration

W is the compile-time data width: 8, 16, or 32 bits. `depth_words` is a construction-time parameter, not another template dimension. Capacity is `depth_words × W/8` bytes. The Python/catalog API also selects W at construction, from those three supported widths. The visualizer labels the model first, for example `MemoryContainer<sram,32>`.

The geometry/timing parameters in [3.3](3.3.md#configuration) also apply. In particular, `words_per_row` controls native row geometry, not the size of a host storage page. The following parameters control simulator resource usage, not physical memory hardware:

| Parameter | Default | Meaning |
| --- | ---: | --- |
| `paged` | 1 | Allocate host storage pages only when a byte differs from its initial fill |
| `max_resident_bytes` | 67,108,864 | Budget for packed content pages/dense data and DRAM row metadata |
| `record_history` | 1 | Keep time-scrubbable memory changes |
| `max_history_bytes` | 16,777,216 | Conservative history-accounting budget; exceeding it stops simulation with a resource error |

Both dense and paged storage preserve four-state data using packed value/known masks. A page covers 4,096 simulated bytes; its data therefore needs 8,192 host bytes, plus accounting overhead. An untouched page costs no content allocation in paged mode. Default fills are X for FF/SRAM/DRAM, zero for ROM, and ones for NOR flash.

These budgets are safeguards, not a limit on total process RSS: components, the simulator's wire history, temporary buffers and allocator overhead also consume memory. History is **bounded by fail-fast rejection**, not silently truncated or evicted. A resource exception stops the run; it is not a retryable bus error. For long performance runs, disable content history when time travel is unnecessary. History cannot be enabled midway through a paged run because that would require a new full history baseline.

For example, Python construction of a 1 MiB SRAM endpoint:

```python
memory = circuit_backend.create_memory_container(
    "MEMORY", "sram", data_width=32, depth_words=262144,
    parameters={"paged": "1", "record_history": "0"},
)
```

Model names are `ff`, `sram`, `dram`, `rom`, and `nor-flash`. The factory defaults to W=32 and N=4096; direct C++ `EndpointConfig` defaults to N=4. A caller can connect directly to this endpoint. `create_memory_controller("BUFFER", "container", ...)` is optional buffering in front of an already-transactional memory, not a requirement for using the container.

## 3.1.6.1. `MemoryContainer<W,Model>`

A single behavioral endpoint; the selected model is fixed at construction.

### IO pins

| Pin | Direction | Width | Description |
| --- | --- | ---: | --- |
| `CLK`, `RST` | Input | 1 | Transaction clock and active-high interface reset |
| `REQ_VALID` | Input | 1 | Request available |
| `REQ_OP` | Input | 3 | READ, WRITE, PROGRAM, or ERASE_BLOCK |
| `REQ_ADDR` | Input | 32 | Aligned byte address |
| `REQ_WRITE_DATA` | Input | W | Positioned write/program data |
| `REQ_WRITE_MASK` | Input | W/8 | Enabled byte lanes |
| `REQ_READY` | Output | 1 | Request can be accepted |
| `RSP_VALID` | Output | 1 | Response available |
| `RSP_READY` | Input | 1 | Response can be consumed |
| `RSP_READ_DATA` | Output | W | Held read result; zero for errors and non-read responses |
| `RSP_STATUS` | Output | 3 | Held completion status |

### Behavior

One request is accepted, executed and answered at a time. Request fields are captured at acceptance. The response stays stable under backpressure. `RST` discards interface state/response delivery but does not clear contents or roll back an already launched device operation.

| Model in `circuit::memory` | Storage and access behavior |
| --- | --- |
| `FFModel` | Unknown initial storage; byte-masked write on the controller-generated device clock; separate read enable |
| `SRAMModel` | Unknown initial storage; asynchronous native selection modeled with access phases; byte-masked replacement writes |
| `DRAMModel` | Open-row buffer, activation/destructive sensing/restoration, column read/write, precharge, periodic row refresh, closed-row retention loss |
| `ROMModel` | Construction-time `image_hex`; zero-filled tail; READ only |
| `NORFlashModel` | Erased ones; WREN before PROGRAM/ERASE; delayed bit-clearing program, block erase, and busy completion |

READ is common to all models. WRITE is accepted only by FF/SRAM/DRAM. PROGRAM and ERASE_BLOCK are explicit NOR operations. Unsupported operations fail; a shared port does not promise that every technology can execute every operation. This is NOR flash, not a NAND page/FTL model.

DRAM refresh uses the same controller policy as the assembled endpoint. It needs continuing bus-clock edges to start maintenance, can operate while a response is held, and cannot restore expired data. Configuration checks the refresh/retention budget, but a stopped or excessively slow caller clock can still miss retention deadlines.

#### C++ example

The example has two parts: `CompactDevice` shows each technology's storage/timing rules, and `Container` shows transaction capture, completion, backpressure, and reset. The documented [3.3 `Sequence`](3.3.md#c-example) handles request validation and native command generation. There is no call to the production `NativeSequence` or `DeviceModel`.

These are **documentation-only classes**, not registered simulator components. Compile the [3.2 port example](3.2.md#c-example), then the first 3.3 example, then this block. Forward reference to 3.3 is necessary because the container includes a controller. The example uses the project's four-state value helpers, configuration validation, and `MemoryStorage` for packed/paged allocation, setup images, history, and resource-budget enforcement; it spells out device and transaction behavior independently. Include paths are `include` and `src/modules/memory`; link `SimulatorLib`.

`CompactDevice` is private to the endpoint: its inputs have already been validated and are held stable by `Sequence`. It is **not** a replacement reference for arbitrary native-pin traffic; use the complete native-device references in 3.1.1–3.1.5 for that. This distinction explains the compact SRAM's single access deadline and the absence of repeated native address validation. FF reset stays low, DRAM refresh is commanded by the sequencer, and NOR changes data only when its program/erase deadline arrives.

```cpp
#include "modules/memory/MemoryContainer.hpp"
#include "MemoryEndpointEngine.hpp" // Internal helpers, reused for this excerpt.
#include <algorithm>
#include <map>

namespace memory_example {
using namespace circuit::memory;

template<std::size_t W, class Model>
class CompactDevice {
    static constexpr auto technology = Model::technology;
    EndpointConfig config_;
    Signals outputs_, latched_;
    LogicValue previous_clock_ = X;
    std::size_t due_ = 0, row_ = 0, col_ = 0, refresh_row_ = 0, address_ = 0;
    unsigned op_ = 0, stage_ = 0;
    bool selected_ = false, open_ = false, enabled_ = false;
    std::map<std::size_t, std::size_t> closed_;
    Bits buffer_, data_, mask_;
    bool edge(const Signals& s) {
        auto clock = signal(s, "CLK")[0];
        bool rising = previous_clock_ == L && clock == H;
        previous_clock_ = clock; return rising;
    }
    void write(std::size_t t, std::size_t word, const Bits& data,
               const Bits& mask, bool program = false) {
        auto old = storage.readLogic(word * (W / 8), W / 8);
        for (std::size_t byte = 0; byte < W / 8; ++byte) if (mask[byte] == H) {
            Bits lane(8);
            for (std::size_t bit = 0; bit < 8; ++bit) {
                auto b = byte * 8 + bit;
                auto d = stored(data[b]); // Z becomes stored X.
                lane[bit] = !program ? d : old[b] == L || d == L ? L :
                            old[b] == H && d == H ? H : X;
            }
            storage.writeLogic(t, word * (W / 8) + byte, lane, true);
        }
    }
    void dram(std::size_t t, const Signals& s) {
        if (due_ && t >= due_) {
            due_ = 0; ++stage_;
            auto first = row_ * config_.words_per_row * (W / 8);
            if (op_ == 1 || op_ == 5) { // ACT or one-row REFRESH.
                if (stage_ == 1) {
                    auto it = closed_.find(row_);
                    auto closed = it == closed_.end() ? 0 : it->second;
                    buffer_ = t - closed >= config_.retention_ticks ? Bits(buffer_.size(), X) :
                              storage.readLogic(first, buffer_.size() / 8);
                    storage.writeLogic(t, first, Bits(buffer_.size(), X)); // Destructive sample.
                } else if (stage_ == 2) storage.writeLogic(t, first, buffer_); // Restore.
                else if (stage_ == 3) {
                    if (op_ == 1) { open_ = true; outputs_["BUSY"] = {L}; }
                    else closed_[row_] = t;
                } else if (stage_ == 5) {
                    refresh_row_ = (refresh_row_ + 1) % (config_.depth_words / config_.words_per_row);
                    outputs_["BUSY"] = {L};
                }
            } else if (op_ == 2) {
                outputs_["READ_DATA"] = Bits(buffer_.begin() + col_ * W, buffer_.begin() + (col_ + 1) * W);
                outputs_["READ_VALID"] = {H}; outputs_["BUSY"] = {L};
            } else if (op_ == 3) {
                if (stage_ == 1) {
                    for (std::size_t b = 0; b < W; ++b)
                        if (mask_[b / 8] == H) buffer_[col_ * W + b] = stored(data_[b]);
                    storage.writeLogic(t, first, buffer_, true);
                } else if (stage_ == 3) outputs_["BUSY"] = {L};
            } else if (op_ == 4) {
                if (stage_ == 1) closed_[row_] = t;
                if (stage_ == 3) { open_ = false; outputs_["BUSY"] = {L}; }
            }
            if (high(outputs_, "BUSY")) due_ = after(t, config_.phase_ticks);
        }
        if (!edge(s)) return;
        auto op = number(signal(s, "CMD", 3)), address = number(signal(s, "ADDR", 32));
        if (!op) return;
        if (high(outputs_, "BUSY")) { outputs_["ERROR"] = {H}; return; }
        outputs_["READ_VALID"] = {L}; outputs_["READ_DATA"] = Bits(W, Z);
        if ((op == 1 && open_) || ((op == 2 || op == 3 || op == 4) && !open_) || (op == 5 && open_)) {
            outputs_["ERROR"] = {H}; return;
        }
        outputs_["ERROR"] = {L}; outputs_["BUSY"] = {H}; op_ = op; stage_ = 0;
        if (op == 1 || op == 5) row_ = op == 1 ? address : refresh_row_;
        if (op == 2 || op == 3) col_ = address;
        if (op == 3) { data_ = signal(s, "WRITE_DATA", W); mask_ = signal(s, "WRITE_MASK", W / 8); }
        due_ = after(t, config_.phase_ticks);
        auto remaining = config_.max_resident_bytes - std::min(config_.max_resident_bytes, storage.allocatedDataBytes());
        if (closed_.size() > remaining / 128) throw std::length_error("DRAM row metadata budget exceeded");
    }
    void flash(std::size_t t, const Signals& s) {
        if (due_ && t >= due_) {
            due_ = 0; ++stage_;
            if (op_ == 1) {
                outputs_["READ_DATA"] = storage.readLogic(address_ * (W / 8), W / 8);
                outputs_["READ_VALID"] = {H}; outputs_["BUSY"] = {L};
            } else if (stage_ == 1) {
                if (op_ == 2) write(t, address_, data_, mask_, true);
                else {
                    auto first = address_ / config_.block_words * config_.block_words;
                    for (auto word = first; word < first + config_.block_words; ++word)
                        storage.writeLogic(t, word * (W / 8), Bits(W, H), true);
                }
                due_ = after(t, config_.phase_ticks);
            } else if (stage_ == 2) due_ = after(t, config_.phase_ticks);
            else outputs_["BUSY"] = {L};
        }
        if (!edge(s)) return;
        auto op = number(signal(s, "CMD", 3));
        if (!op) return;
        outputs_["ERROR"] = {L}; outputs_["READ_VALID"] = {L}; outputs_["READ_DATA"] = Bits(W, Z);
        if (high(outputs_, "BUSY") || ((op == 2 || op == 3) && !enabled_)) {
            outputs_["ERROR"] = {H}; return;
        }
        if (op == 4 || op == 5) { enabled_ = op == 4; return; }
        op_ = op; stage_ = 0; address_ = number(signal(s, "WORD_ADDR", 32));
        data_ = signal(s, "WRITE_DATA", W); mask_ = signal(s, "WRITE_MASK", W / 8);
        if (op != 1) enabled_ = false;
        outputs_["BUSY"] = {H};
        due_ = after(t, op == 1 ? config_.phase_ticks : op == 2 ? config_.program_ticks : config_.erase_ticks);
    }
public:
    MemoryStorage storage; // Storage mechanics only; all device rules are above/below.
    explicit CompactDevice(EndpointConfig c)
        : config_(c), buffer_(W * c.words_per_row, X),
          storage(c.depth_words, W, technology == Technology::ROM ? L : technology == Technology::NORFlash ? H : X,
                  c.record_history, {c.paged, c.max_resident_bytes, c.max_history_bytes}) {
        outputs_["READ_DATA"] = Bits(W, Z);
        for (auto p : {"BUSY", "ERROR", "READ_VALID", "FAULT"}) outputs_[p] = {L};
        if constexpr (technology == Technology::ROM) {
            std::vector<std::uint8_t> image;
            for (std::size_t i = 0; i < c.image_hex.size(); i += 2)
                image.push_back(std::stoul(c.image_hex.substr(i, 2), nullptr, 16));
            storage.loadBytes(0, image);
        }
    }
    Bits read(const std::string& pin, std::size_t width) const { return signal(outputs_, pin, width); }
    std::size_t deadline() const { return due_; }
    void update(std::size_t t, const Signals& s) {
        if constexpr (technology == Technology::FF) {
            bool rising = edge(s); auto word = number(signal(s, "WORD_ADDR", 32));
            if (rising && high(s, "WE")) write(t, word, signal(s, "WRITE_DATA", W), signal(s, "WRITE_MASK", W / 8));
            outputs_["READ_DATA"] = high(s, "READ_EN") ? storage.readLogic(word * (W / 8), W / 8) : Bits(W, L);
        } else if constexpr (technology == Technology::SRAM) {
            if (high(s, "CE_N")) {
                selected_ = false; due_ = 0; outputs_["READ_DATA"] = Bits(W, Z); return;
            }
            if (!selected_) { selected_ = true; latched_ = s; due_ = after(t, 4 * config_.phase_ticks); }
            if (!due_ || t < due_) return;
            due_ = 0; auto word = number(signal(latched_, "WORD_ADDR", 32));
            if (!high(latched_, "WE_N"))
                write(t, word, signal(latched_, "WRITE_DATA", W), signal(latched_, "WRITE_MASK", W / 8));
            else outputs_["READ_DATA"] = storage.readLogic(word * (W / 8), W / 8);
        } else if constexpr (technology == Technology::ROM) {
            outputs_["READ_DATA"] = high(s, "CE_N") || high(s, "OE_N") ? Bits(W, Z) :
                storage.readLogic(number(signal(s, "WORD_ADDR", 32)) * (W / 8), W / 8);
        } else if constexpr (technology == Technology::DRAM) dram(t, s);
        else if constexpr (technology == Technology::NORFlash) flash(t, s);
    }
};

template<std::size_t W, class Model>
class Container {
    static_assert(W == 8 || W == 16 || W == 32);
public:
    struct Inputs {
        bool rising_edge = false, reset = false;
        bool request_valid = false, response_ready = false;
        Request request{bits(3, 0), bits(32, 0), Bits(W, L), Bits(W / 8, L)};
    };
    struct Outputs {
        bool request_ready = false, response_valid = false;
        Bits read_data = Bits(W, L);
        Status status = Status::Ok;
    };

    explicit Container(EndpointConfig config)
        : config_(checked(config)), sequence_(W, Model::technology, config_),
          device_(config_) {}

    const MemoryStorage& storage() const { return device_.storage; }

    Outputs step(std::size_t time, const Inputs& in) {
        if (in.reset) {
            phase_ = Phase::Idle;
            out_.read_data.assign(W, L);
            out_.status = Status::Ok; // Contents and launched work are not erased.
        } else if (in.rising_edge) {
            switch (phase_) {
            case Phase::Idle:
                if (sequence_.available && in.request_valid) {
                    request_ = in.request;
                    phase_ = Phase::Latched;
                }
                break;
            case Phase::Latched:
                phase_ = Phase::Execute;
                break;
            case Phase::Execute:
                if (sequence_.done) {
                    out_.read_data = sequence_.result;
                    out_.status = sequence_.status;
                    phase_ = Phase::Respond;
                }
                break;
            case Phase::Respond:
                if (in.response_ready) phase_ = Phase::Idle;
                break;
            }
        }

        // Settle prior device work, drive native controls, then update the device.
        device_.update(time, sequence_.outputs);
        sequence_.step(time, in.rising_edge, in.reset, phase_ == Phase::Execute,
                       request_, [&](const std::string& pin, std::size_t width) {
                           return device_.read(pin, width);
                       });
        device_.update(time, sequence_.outputs);

        out_.request_ready = !in.reset && phase_ == Phase::Idle && sequence_.available;
        out_.response_valid = !in.reset && phase_ == Phase::Respond;
        return out_;
    }

    // The caller must also step at native deadlines, not only at bus-clock edges.
    std::size_t next_event_time() const {
        auto a = sequence_.deadline(), b = device_.deadline();
        return a == 0 ? b : b == 0 ? a : std::min(a, b); // 0: no timed event.
    }

private:
    static EndpointConfig checked(EndpointConfig config) {
        config.validate(W, Model::technology);
        return config;
    }
    enum class Phase { Idle, Latched, Execute, Respond };
    EndpointConfig config_;
    Sequence sequence_;
    CompactDevice<W, Model> device_;
    Phase phase_ = Phase::Idle;
    Request request_{bits(3, 0), bits(32, 0), Bits(W, L), Bits(W / 8, L)};
    Outputs out_;
};

auto make_sram_example() {
    EndpointConfig config;
    config.depth_words = 4096; // 4096 words × 4 bytes = 16 KiB.
    return Container<32, SRAMModel>(config);
}
} // namespace memory_example
```

`Inputs::request` holds operation, byte address, W data bits, and W/8 byte-enable bits. For example, `Request{bits(3, unsigned(Operation::Read)), bits(32, 12), Bits(32, L), Bits(4, L)}` reads word 3 of a 32-bit container. Hold `request_valid` and its payload until a rising edge with `request_ready`. The returned `read_data` and `status` are meaningful when `response_valid` is true, and remain held until a rising edge with `response_ready`. The request/response rules are defined in [3.2](3.2.md).

`step` receives an already-detected rising edge instead of simulator pins. Call it in chronological order for input changes, clock edges, and every nonzero `next_event_time()`; a deadline call is not itself a clock edge. The real component connects these operations to wire events, scheduled evaluations, and pin history. Binary control flags simplify the excerpt, but payload and stored bits still support X/Z. No event loop or pin-wiring code is shown.

Changing `SRAMModel` to `FFModel`, `DRAMModel`, `ROMModel`, or `NORFlashModel` selects another existing device model, not a different generic byte assignment. `storage()` is a read-only inspector view; it does not bypass the request path to mutate contents. ERASE_BLOCK affects a whole validated NOR block and ignores the write mask. Row activation/refresh remain internal controller operations, not caller opcodes; their sequencing belongs to [3.3](3.3.md).

`MemoryEndpointIntegrationTest` extracts these exact code blocks and executes storage, transaction, and technology-specific checks. Sequencing and device rules are implemented by the documented references, independently of the production sequencer/device classes. Value helpers and packed storage mechanics remain shared, so this is not an independent oracle for their internals. Native-device equivalence is additionally covered by `MemoryEndpointContractTest`.

#### Unknown inputs and timing

The common protocol's binary handshake requirement and request-validation order apply unchanged. Unknown read contents are returned as X with success, not converted to zero. Enabled X/Z write-data bits become unknown stored bits. For NOR programming, zero dominates: programming zero into an unknown bit produces a known zero; programming one cannot recover an unknown bit.

Configured ticks describe this simulator's digital device phases. They are not calibrated SRAM/DDR/flash timing or energy measurements. The compact and assembled implementations agree on operations, errors and checkpoint results; their internal propagation timestamps need not match. A request may not complete before its modeled device operation has finished.

### Implementation

#### Behavioral implementation

The public template delegates to `BehavioralMemoryContainer`. Internally it combines a transaction state machine, the same native command sequencer used by `MemoryController`, and a separate technology-specific device model. `MemoryStorage` supplies dense or paged four-state contents and optional history. It does not decide ROM permissions, flash programming, or DRAM refresh: those rules belong to the selected device/controller model.

The catalog exposes `memory.scalable.<technology>.<W>` as behavioral-only. `memory.endpoint.<technology>.<W>` offers the assembled and compact alternatives under one transaction contract. Compact equivalence is checked against independently built native devices; reusing the controller sequencer alone is not evidence of storage equivalence.

The memory inspector uses `MemoryStateView` to show a bounded word window at the selected simulation time. Inspection does not issue a memory transaction. DRAM idle expiry is checked lazily on activation/refresh; an untouched backing snapshot is not proof that a charge has survived retention. There is no unrestricted runtime contents-loader. `initializeBytes(address, bytes)` and `clearContents()` provision a host image only **before the first simulator evaluation**; later calls throw, including after reset. `clearContents()` explicitly supplies a zero-filled test/program image; it is not the SRAM/DRAM power-on state. This setup facility is used by the RV32I program and ELF loaders. ROM also supports construction-time `image_hex`. Once running, all modifications use transactions and retain the technology's write/program/erase rules. Nonvolatile storage persists within a component instance, not automatically across closing/recreating the simulator.

For existing array-pin callers, the older implementation remains available as `LegacyMemoryContainer` and Python `create_memory_array`. Its catalog IDs and tests remain intact. `MemoryBusAdapter32` still adapts that legacy array contract; it is **not** the new transaction controller. Existing RV32I cores have not been silently rewired to a variable-latency interface.
