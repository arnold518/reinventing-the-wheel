# § 3.3. Memory Controllers

Controllers translate [memory transactions](3.2.md) into the different native interfaces in [3.1](3.1/index.md). They own request/response state, not memory contents. A complete endpoint connects a controller to a separate memory device.

| Component | Description | Structural | Behavioral |
| --- | --- | :---: | :---: |
| `MemoryController<T,W>` | Zero-wait FF path or delayed technology-specific control | Yes | Yes |
| `MemoryEndpoint<T,W>` | Controller plus native device, or a fused behavioral endpoint | Yes | Yes |

T is `ff`, `sram`, `dram`, `rom`, or `nor-flash`; W is 8, 16, or 32. Angle brackets describe dimensions in visualizer labels; the C++ controller/endpoint constructors take width and technology as arguments.

All RV32I cores use this universal endpoint interface. The single-cycle core and baseline pipeline select zero-wait FF endpoints; the transaction-capable pipeline can also use delayed technologies. A controller translates interfaces. For the flip-flop technology it imposes no cycle delay. A delayed technology finishes at a moment unrelated to the clock, so its completion is first captured on a clock edge ([3.2](3.2.md)); that costs one cycle per access. Capacity alone never requires a delay.

## Configuration

Controller and native device must agree on depth, row/block geometry, and timing. `MemoryEndpoint` constructs matching pairs. Standalone-controller users must connect a device with the same configuration.

| Parameter | Default | Meaning |
| --- | ---: | --- |
| `depth_words` | 4 | Addressable words; capacity is N×W/8 bytes |
| `words_per_row` | 2 | Matrix words per row; 1/2/4/8/16 dividing N |
| `block_words` | 2 | NOR erase block; whole rows dividing N |
| `phase_ticks` | 32 | Native device phase spacing |
| `guard_ticks` | 64 | Setup/recovery interval around native command strobes; minimum 64 |
| `program_ticks`, `erase_ticks` | 128, 256 | NOR operation intervals |
| `retention_ticks` | 1,000,000,000 | DRAM closed-row retention interval |
| `refresh_interval_ticks` | 10,000 | Controller refresh-start target; 0 deliberately disables refresh |
| `image_hex` | Empty | ROM construction-time image; unspecified tail is zero |
| `always_ready` | 0 | FF-only zero-wait contract: require `RSP_READY=1` and omit response retention |

Capacity must be nonzero and fit below 2^32 bytes. Matrix geometry applies to SRAM/DRAM/ROM/NOR, and block geometry only to NOR. FF ignores the native phase/guard/program timing fields; its cycle must still allow the circuit to settle. For delayed controllers, accepted timing ranges are 32…10,000 for phase ticks, 64…1,000,000 for guards, phase…1,000,000 for programming, program…10,000,000 for erase, and 1,024…1,000,000,000 for DRAM retention. Refresh configuration must additionally meet the retention coverage check below. Unsupported values are rejected during construction.

Expanded endpoint storage is limited to 4,096 cells. Request `memory.<technology>.scalable-endpoint.<width>` instead of `memory.<technology>.endpoint.<width>` to keep the controller visible while attaching a scalable native `MemoryContainer`; this removes the cell-expansion limit, not native timing or host resource limits. Standalone controllers do not allocate those cells. The universal interface does not make native SRAM/ROM suddenly clocked: their controller is clocked, while their access pins remain asynchronous. Device command strobes are generated with explicit setup/recovery guards; this is a digital simulator controller, not a calibrated DDR PHY.

## 3.3.1. `MemoryController<T,W>`

Connects a requester to an external native device, or buffers another transaction endpoint.

### IO pins

The requester side is exactly the [common protocol](3.2.md#io-pins): CLK/RST, REQ_VALID/READY, REQ_OP, REQ_ADDR, REQ_WRITE_DATA/MASK, RSP_VALID/READY, RSP_READ_DATA/STATUS. Backend-only START/FINISH/DONE pins are internal, not part of this component's public interface.

Native pin names have a `MEM_` prefix. Directions below are relative to the controller.

| Technology | Controller outputs → device inputs | Device outputs → controller inputs |
| --- | --- | --- |
| FF | `MEM_WORD_ADDR<32>`, `MEM_WRITE_DATA<W>`, `MEM_WRITE_MASK<W/8>`, `MEM_CLK`, `MEM_RST`, `MEM_WE`, `MEM_READ_EN` | `MEM_READ_DATA<W>`, `MEM_FAULT` |
| SRAM | `MEM_WORD_ADDR<32>`, `MEM_WRITE_DATA<W>`, `MEM_WRITE_MASK<W/8>`, `MEM_CE_N`, `MEM_WE_N`, `MEM_OE_N` | `MEM_READ_DATA<W>` |
| ROM | `MEM_WORD_ADDR<32>`, `MEM_CE_N`, `MEM_OE_N` | `MEM_READ_DATA<W>` |
| DRAM | `MEM_ADDR<32>`, `MEM_WRITE_DATA<W>`, `MEM_WRITE_MASK<W/8>`, `MEM_CLK`, `MEM_CMD<3>` | `MEM_READ_DATA<W>`, `MEM_BUSY`, `MEM_ERROR`, `MEM_READ_VALID` |
| NOR flash | `MEM_WORD_ADDR<32>`, `MEM_WRITE_DATA<W>`, `MEM_WRITE_MASK<W/8>`, `MEM_CLK`, `MEM_CMD<3>` | `MEM_READ_DATA<W>`, `MEM_BUSY`, `MEM_ERROR`, `MEM_READ_VALID` |

Unannotated controls/status pins are one bit. Native FF reset is held low: protocol reset does not clear its storage. A reset during a launched operation suppresses the abandoned response but does not undo an accepted write.

### Behavior

For FF, validation and reads are combinational and accepted writes use the shared clock. For delayed devices, the sequencer captures and translates request fields on the acceptance edge. Invalid requests never issue native operations. Results are captured before native pins are released and are held independently of subsequent device activity.

| Technology | Access sequence |
| --- | --- |
| FF | Validate/address-map combinationally → read during the cycle or write on its shared rising edge; response bypasses empty buffer |
| SRAM | Select CE/WE/OE and stable payload → wait four native phases plus guards → capture/release |
| ROM | Select address/output → wait settling interval → capture/release; reject modifications |
| DRAM | Reuse matching open row; otherwise PRECHARGE if needed, ACTIVATE row, READ/WRITE slot; wait for completion |
| NOR flash | READ, or WREN followed by PROGRAM/ERASE; wait BUSY, check ERROR and read-valid |

DRAM refresh is serviced when the bus clock runs, including while a response is held under backpressure. Due refresh is inserted before an accepted DRAM access, so continuous traffic cannot starve maintenance. It closes an open row before issuing REFRESH. Configuration rejects a refresh schedule that cannot cover all rows within retention, including a conservative access-service allowance. Stopping the bus clock also stops starting maintenance; data can expire. REFRESH cannot recover already lost data. Timing experiments with refresh disabled must use finite simulation windows and expect retention effects.

#### C++ example

The controller combines the `Port<W>` reference from [3.2](3.2.md#c-example) with the explicit `Sequence` reference below. It owns **no device and no backing storage**. Request validation, native pin generation, command queues, refresh, error handling, and reset draining are shown here; no production sequencer is called. The caller supplies device feedback through `read_native` and connects `native_pins()` to a separate device.

`Sequence` and `Controller` below are documentation-only reference classes, not registered components. Paste 3.2 before this excerpt. Only the project's value/configuration types and small signal/conversion helpers are reused (`Bits`, `Request`, `Signals`, `signal`, `high`, `bits`, `number`, `known`, and overflow-checked `after`). Pin dictionary keys omit the public `MEM_` prefix. Call at input changes and each nonzero deadline. One transition runs per deadline; a stopped bus clock does not stop an already scheduled native command, but does stop starting new refresh maintenance.

```cpp
// Requires memory_example::Port<W> from the 3.2 example.
#include "MemoryEndpointEngine.hpp"

namespace memory_example {
class Sequence {
    enum class Phase { Idle, Setup, ClockHigh, Capture, StaticAccess,
                       CommandHigh, CommandLow, CommandWait, Release };
    struct Command { unsigned op; std::uint32_t address; };
    std::size_t width_, due_ = 0, next_refresh_ = 0, row_ = 0;
    Technology technology_;
    EndpointConfig config_;
    Phase phase_ = Phase::Idle;
    Request request_;
    std::deque<Command> commands_;
    bool aborted_ = false, maintenance_ = false, row_open_ = false, rested_ = false;

public:
    Status validate(const Request& r) const {
        if (!known(r.op) || !known(r.address)) return Status::InvalidRequest;
        const auto op = number(r.op), a = number(r.address);
        if (op > 3) return Status::Unsupported;
        if ((op == 1 || op == 2) && !known(r.mask)) return Status::InvalidRequest;
        if (a % (width_ / 8)) return Status::Alignment;
        if (a / (width_ / 8) >= config_.depth_words) return Status::Range;
        if (technology_ == Technology::ROM && op) return Status::ReadOnly;
        if (technology_ == Technology::NORFlash) {
            if (op == 1) return Status::Unsupported;
            if (op == 3 && (a / (width_ / 8)) % config_.block_words) return Status::Alignment;
        } else if (op > 1) return Status::Unsupported;
        return Status::Ok;
    }
private:
    void idle() {
        for (auto p : {"CLK", "RST", "WE", "READ_EN", "REQ_VALID", "RSP_READY"}) outputs[p] = {L};
        for (auto p : {"CE_N", "WE_N", "OE_N"}) outputs[p] = {H};
        for (auto p : {"CMD", "REQ_OP"}) outputs[p] = bits(3, 0);
        for (auto p : {"ADDR", "WORD_ADDR", "REQ_ADDR"}) outputs[p] = bits(32, 0);
        outputs["WRITE_DATA"] = outputs["REQ_WRITE_DATA"] = Bits(width_, L);
        outputs["WRITE_MASK"] = outputs["REQ_WRITE_MASK"] = Bits(width_ / 8, L);
    }
    void finish(std::size_t t) {
        idle(); phase_ = Phase::Release; due_ = after(t, config_.guard_ticks);
    }
    void command(std::size_t t) {
        if (commands_.empty()) { finish(t); return; }
        outputs["CLK"] = {L}; outputs["CMD"] = bits(3, commands_.front().op);
        outputs["ADDR"] = outputs["WORD_ADDR"] = bits(32, commands_.front().address);
        phase_ = Phase::CommandHigh; due_ = after(t, config_.guard_ticks);
    }
public:
    bool done = false, available = true;
    Bits result;
    Status status = Status::Ok;
    Signals outputs;
    Sequence(std::size_t w, Technology technology, EndpointConfig config)
        : width_(w), technology_(technology), config_(config), result(w, L) { idle(); }
    std::size_t deadline() const { return due_; }
    void step(std::size_t t, bool edge, bool reset, bool start, const Request& request,
              const std::function<Bits(const std::string&, std::size_t)>& read, bool finish_response = false) {
        if (edge && finish_response) done = false;
        if (reset) aborted_ = true; // Drain launched work; suppress its response.
        if (phase_ == Phase::Idle) {
            if (reset) { done = false; available = false; rested_ = false; return; }
            available = true;
            if (done) return;
            const bool refresh_due = technology_ == Technology::DRAM &&
                config_.refresh_interval_ticks && t >= next_refresh_;
            // The requester sees "ready" one edge after the backend goes idle;
            // a refresh waits for that idle edge too, so a waiting request is
            // never overtaken by one refresh after another.
            const bool refresh = refresh_due && edge && !start && rested_;
            if (edge) rested_ = true;
            if (!(start && edge) && !refresh) { aborted_ = false; return; }
            rested_ = false;
            aborted_ = false; maintenance_ = refresh; available = false;
            status = Status::Ok; result.assign(width_, L); commands_.clear();
            if (refresh) { // Idle maintenance; no request was accepted.
                if (row_open_) commands_.push_back({4, 0});
                commands_.push_back({5, 0});
                next_refresh_ = after(t, config_.refresh_interval_ticks);
                command(t); return;
            }
            request_ = request; status = validate(request);
            if (status != Status::Ok) { finish(t); return; }
            const auto op = number(request.op);
            const auto word = number(request.address) / (width_ / 8);
            outputs["WORD_ADDR"] = bits(32, word);
            outputs["WRITE_DATA"] = request.data; outputs["WRITE_MASK"] = request.mask;
            if (technology_ == Technology::FF) {
                phase_ = Phase::Setup; due_ = after(t, config_.guard_ticks); return;
            }
            if (technology_ == Technology::SRAM || technology_ == Technology::ROM) {
                outputs["CE_N"] = {L}; outputs["WE_N"] = {op == 1 ? L : H};
                outputs["OE_N"] = {op == 0 ? L : H};
                phase_ = Phase::StaticAccess;
                due_ = after(t, 4 * config_.phase_ticks + 2 * config_.guard_ticks); return;
            }
            if (technology_ == Technology::DRAM) {
                const auto row = word / config_.words_per_row;
                if (refresh_due) {
                    if (row_open_) commands_.push_back({4, 0});
                    commands_.push_back({5, 0});
                    next_refresh_ = after(t, config_.refresh_interval_ticks);
                } else if (row_open_ && row_ != row) commands_.push_back({4, 0});
                if (refresh_due || !row_open_ || row_ != row) commands_.push_back({1, std::uint32_t(row)});
                commands_.push_back({op == 0 ? 2u : 3u, std::uint32_t(word % config_.words_per_row)});
            } else {
                if (op) commands_.push_back({4, 0}); // WREN before either mutation.
                commands_.push_back({op == 0 ? 1u : op == 2 ? 2u : 3u, std::uint32_t(word)});
            }
            command(t); return;
        }
        available = false;
        if (!due_ || t < due_) return;
        due_ = 0;
        switch (phase_) {
        case Phase::Setup:
            outputs["WE"] = {number(request_.op) == 1 ? H : L};
            outputs["READ_EN"] = {number(request_.op) == 0 ? H : L};
            phase_ = Phase::ClockHigh; due_ = after(t, config_.guard_ticks); break;
        case Phase::ClockHigh:
            outputs["CLK"] = {H}; phase_ = Phase::Capture; due_ = after(t, config_.guard_ticks); break;
        case Phase::Capture:
            if (read("FAULT", 1) != Bits{L}) status = Status::Device;
            if (number(request_.op) == 0) result = read("READ_DATA", width_);
            finish(t); break;
        case Phase::StaticAccess:
            if (number(request_.op) == 0) result = read("READ_DATA", width_);
            finish(t); break;
        case Phase::CommandHigh:
            outputs["CLK"] = {H}; phase_ = Phase::CommandLow; due_ = after(t, config_.guard_ticks); break;
        case Phase::CommandLow: {
            outputs["CLK"] = {L}; outputs["CMD"] = bits(3, 0);
            auto op = commands_.front().op;
            std::size_t wait = config_.phase_ticks;
            if (technology_ == Technology::DRAM) wait *= op == 5 ? 5 : op == 2 ? 1 : 3;
            else if (op == 2 || op == 3)
                wait = (op == 2 ? config_.program_ticks : config_.erase_ticks) + 2 * config_.phase_ticks;
            phase_ = Phase::CommandWait; due_ = after(t, wait + config_.guard_ticks); break;
        }
        case Phase::CommandWait: {
            if (read("BUSY", 1) != Bits{L}) { due_ = after(t, config_.guard_ticks); break; }
            if (read("ERROR", 1) != Bits{L}) { status = Status::Device; commands_.clear(); finish(t); break; }
            auto cmd = commands_.front(); commands_.pop_front();
            if (technology_ == Technology::DRAM) {
                if (cmd.op == 1) { row_open_ = true; row_ = cmd.address; }
                if (cmd.op == 4) row_open_ = false;
            }
            if ((technology_ == Technology::DRAM && cmd.op == 2) ||
                (technology_ == Technology::NORFlash && cmd.op == 1)) {
                if (read("READ_VALID", 1) != Bits{H}) status = Status::Device;
                else result = read("READ_DATA", width_);
            }
            command(t); break;
        }
        case Phase::Release:
            phase_ = Phase::Idle; done = !maintenance_ && !aborted_;
            available = !reset; break;
        default: break;
        }
        if (status != Status::Ok) result.assign(width_, L);
    }
};

template<std::size_t W>
class Controller {
    static EndpointConfig checked(Technology t, EndpointConfig c) { c.validate(W,t); return c; }
    Technology technology_;
    bool always_ready_;
    Port<W> port_;
    ResponseBuffer<W> response_; // Used by the buffered FF configuration.
    Sequence sequence_;         // Only stepped for delayed technologies.
    Signals pins_;
    bool previous_clock_ = false;
public:
    struct Inputs {
        bool clock = false, reset = false;
        bool request_valid = false, response_ready = false;
        Request request{bits(3, 0), bits(32, 0), Bits(W, L), Bits(W / 8, L)};
    };
    Controller(Technology t, EndpointConfig c)
        : technology_(t), always_ready_(c.always_ready),
          sequence_(W,t,checked(t,c)), pins_(sequence_.outputs) {}
    const Signals& native_pins() const { return pins_; }
    std::size_t next_event_time() const { return sequence_.deadline(); }

    typename Port<W>::Outputs step(std::size_t time, const Inputs& in,
        const std::function<Bits(const std::string&, std::size_t)>& read_native) {
        const bool edge = !previous_clock_ && in.clock;
        previous_clock_ = in.clock;
        if (technology_ == Technology::FF) {
            typename ResponseBuffer<W>::Inputs r;
            r.reset=in.reset; r.edge=edge; r.ready=in.response_ready;
            const bool accept=in.request_valid &&
                (always_ready_ ? !in.reset : response_.outputs(r).ready);
            auto status=sequence_.validate(in.request);
            const auto op=number(in.request.op);
            pins_["CLK"]={in.clock?H:L}; pins_["RST"]={L};
            pins_["WORD_ADDR"]=bits(32,number(in.request.address)/(W/8));
            pins_["WRITE_DATA"]=in.request.data; pins_["WRITE_MASK"]=in.request.mask;
            pins_["WE"]={accept && status==Status::Ok && op==1?H:L};
            pins_["READ_EN"]={accept && status==Status::Ok && op==0?H:L};
            // The caller settles the separate native device before feedback.
            const auto data=read_native("READ_DATA",W);
            if (status==Status::Ok && read_native("FAULT",1)==Bits{H}) status=Status::Device;
            r.valid=accept; r.status=bits(3,unsigned(status));
            r.data=status==Status::Ok && op==0?data:Bits(W,L);
            if (always_ready_)
                return {!in.reset,accept,false,false,in.request,r.data,r.status};
            response_.step(r);
            auto out=response_.outputs(r);
            // Recompute bypass VALID when capture has filled the buffer.
            r.valid=in.request_valid && out.ready;
            out=response_.outputs(r);
            return {out.ready,out.valid,false,false,in.request,out.data,out.status};
        }
        typename Port<W>::Inputs front;
        front.rising_edge=edge; front.reset=in.reset;
        front.request_valid=in.request_valid; front.response_ready=in.response_ready;
        front.request=in.request; front.backend_ready=sequence_.available;
        front.done=sequence_.done; front.result=sequence_.result;
        front.status=bits(3,unsigned(sequence_.status));
        const auto before=port_.outputs(front);
        port_.step(front);
        sequence_.step(time,edge,in.reset,before.start,in.request,read_native,before.finish);
        pins_=sequence_.outputs;
        front.backend_ready=sequence_.available; front.done=sequence_.done;
        front.result=sequence_.result; front.status=bits(3,unsigned(sequence_.status));
        return port_.outputs(front);
    }
};
} // namespace memory_example
```

The delayed port tracks pending work and retains responses only when needed; the sequencer captures and validates fields, maps byte addresses to native addresses, issues commands, and waits for device completion. For DRAM this includes row changes and refresh. For NOR it includes WREN, PROGRAM/ERASE, and BUSY/error handling. For `Technology::Container` it forwards transactions and the bus clock to another endpoint. There is no generic “one delayed array access” replacing these sequences.

Start with reset asserted and a known-low clock. Step at input changes, clock changes, and every sequencer/device deadline; settle the separate device before sampling its feedback, then update it with the new native outputs. `Signals` uses unprefixed native names (`CLK`, `CMD`, etc.); the actual controller exposes these as `MEM_*` pins. The returned view includes the frontend's internal START/payload for inspection; those are not additional public controller pins. Gate propagation and wire scheduling are omitted, not device timing or reset-draining policy.

This reference is a teaching listing, separate from the registered behavioral controller described under Implementation. Tests execute it with separate FF/SRAM/DRAM/ROM/NOR models, including reset during programming. Invalid requests must not issue a native access for that request; independent DRAM refresh may still proceed.

#### Unknown inputs and timing

Handshake controls must be binary. Required unknown payload fields return INVALID_REQUEST; unknown read contents remain X and are not a readiness signal. Native BUSY/ERROR/READ_VALID must settle before completion. The controller does not guess completion from READ_DATA and has no implicit timeout that could cause a store to be retried twice. Clock setup/hold requirements apply to structural paths; command guards apply only to timed native operations. Reset suppresses response delivery but drains a launched sequence; it cannot roll back its side effects.

### Implementation

#### Structural implementation

For FF, `REQUEST_CHECK` is structural address/operation validation. Power-of-two byte capacities use a balanced high-address-bit check; other capacities use a balanced constant comparison. The general FF controller uses `RESPONSE`, the fall-through FF buffer. With `always_ready=1`, the consumer must keep `RSP_READY=1`; the controller instead sends the accepted response directly in the same cycle and stores no response payload. This mode is used by the fixed-cycle RV32I cores, while the general and advanced-pipeline endpoints retain backpressure support. There is no native command sequencer or extra cycle. For delayed technologies, `TRANSACTION` is the gate/FF-built frontend from 3.2. `DEVICE_CONTROL` is an explicitly named terminal **timed digital sequencer**, not an expanded gate-level FSM or analog model. It holds native command state and deadlines but no contents. This classification is intentional: the register/control boundary is visible, while technology access sequencing is a primitive, like the existing native device command controls.

#### Behavioral implementation

[`MemoryControllerBehavioral`](https://github.com/arnold518/reinventing-the-wheel/blob/github-pages/src/modules/memory/MemoryController.cpp) is the whole controller as one part. It keeps the same state as the structural form (one pending request, one held response, and the native sequencer's phase) and applies the same rules: the flip-flop path validates and answers in the same cycle, and the other technologies step the shared `NativeSequence` that the structural sequencer also uses, so native pin activity is identical. It owns no device and no storage. An endpoint requests its controller through the catalog, so a profile can show the controller as gates or as this one part; `MemoryEndpointContractTest` compares the two in front of the same device for all five technologies.

## 3.3.2. `MemoryEndpoint<T,W>`

Assembly of `CONTROLLER` and `MEMORY`. Unlike a standalone controller, this component includes actual storage. Its fused behavioral implementation is `BehavioralMemoryEndpoint`, replacing both controller and device at this boundary. A [MemoryContainer](3.1.6.md) replaces only the native device and keeps that device's pins.

### IO pins

| Pin | Direction | Width | Description |
| --- | --- | ---: | --- |
| `CLK`, `RST`, `REQ_VALID`, `RSP_READY` | Input | 1 | Shared clock, interface reset, handshakes |
| `REQ_OP` | Input | 3 | Operation |
| `REQ_ADDR` | Input | 32 | Aligned byte address |
| `REQ_WRITE_DATA` | Input | W | Positioned data |
| `REQ_WRITE_MASK` | Input | W/8 | Byte enables |
| `REQ_READY`, `RSP_VALID` | Output | 1 | Request acceptance / response available |
| `RSP_READ_DATA` | Output | W | Result |
| `RSP_STATUS` | Output | 3 | Status |

### Behavior

The shared protocol and selected technology rules apply unchanged. Native addresses, enables and command status remain visible inside the assembled endpoint.

#### C++ example

The endpoint adds wiring and evaluation order, not another memory algorithm. This reference owns the preceding controller and a separately supplied device reference. `Device` provides `update(time,pins)`, `read(pin,width)`, and `deadline()`; `CompactDevice` below is one usable implementation for the controller's valid command stream. Both receive the same validated configuration. `CompactEndpoint` below spells out the equivalent pending/response state and the FF bypass. Neither representation adds an endpoint state machine beyond its controller.

Call `step` on input changes and at the earliest reported deadline, as for the constituent references. The factory at the bottom shows how to construct the actual simulator component; it is separate from the reference algorithm.

```cpp
#include "components/Component.hpp"
#include "modules/memory/MemoryController.hpp"
#include <algorithm>
namespace memory_example {
template<std::size_t W, class Device>
struct Endpoint {
    Technology technology;
    Controller<W> controller;
    Device device;
    Endpoint(Technology t, EndpointConfig config)
        : technology(t), controller(t, config), device(config) {}
    auto step(std::size_t time, const typename Controller<W>::Inputs& in) {
        device.update(time, controller.native_pins());
        auto out = controller.step(time, in, [&](const std::string& pin, std::size_t width) {
            if (technology == Technology::FF) device.update(time, controller.native_pins());
            return device.read(pin, width);
        });
        device.update(time, controller.native_pins());
        return out;
    }
    std::size_t next_event_time() const {
        auto a = controller.next_event_time(), b = device.deadline();
        return a == 0 ? b : b == 0 ? a : std::min(a, b);
    }
};
} // namespace memory_example

std::shared_ptr<MemoryEndpoint> make_sram_endpoint() {
    circuit::memory::EndpointConfig config;
    config.depth_words = 4;
    config.words_per_row = 2;
    return Component::create<MemoryEndpoint>("MEMORY", 8, circuit::memory::Technology::SRAM, config);
}

// Fused behavioral endpoint reference. CompactDevice below is valid only for
// the validated, stable native command stream generated by Sequence. For
// arbitrary native pin traffic, use the complete references in 3.1.1–3.1.5.

using namespace circuit::memory;

template<std::size_t W, class Model>
class CompactDevice {
    static constexpr auto technology = Model::technology;
    EndpointConfig config_;
    Signals outputs_, latched_;
    LogicValue previous_clock_ = X;
    std::size_t due_ = 0, row_ = 0, col_ = 0, refresh_row_ = 0, address_ = 0;
    unsigned op_ = 0, stage_ = 0;
    bool selected_ = false, open_ = false, enabled_ = false;
    std::map<std::size_t, std::size_t> closed_;
    Bits buffer_, data_, mask_;
    bool edge(const Signals& s) {
        auto clock = signal(s, "CLK")[0];
        bool rising = previous_clock_ == L && clock == H;
        previous_clock_ = clock; return rising;
    }
    void write(std::size_t t, std::size_t word, const Bits& data,
               const Bits& mask, bool program = false) {
        auto old = storage.readLogic(word * (W / 8), W / 8);
        for (std::size_t byte = 0; byte < W / 8; ++byte) if (mask[byte] == H) {
            Bits lane(8);
            for (std::size_t bit = 0; bit < 8; ++bit) {
                auto b = byte * 8 + bit;
                auto d = stored(data[b]); // Z becomes stored X.
                lane[bit] = !program ? d : old[b] == L || d == L ? L :
                            old[b] == H && d == H ? H : X;
            }
            storage.writeLogic(t, word * (W / 8) + byte, lane, true);
        }
    }
    void dram(std::size_t t, const Signals& s) {
        if (due_ && t >= due_) {
            due_ = 0; ++stage_;
            auto first = row_ * config_.words_per_row * (W / 8);
            if (op_ == 1 || op_ == 5) { // ACT or one-row REFRESH.
                if (stage_ == 1) {
                    auto it = closed_.find(row_);
                    auto closed = it == closed_.end() ? 0 : it->second;
                    buffer_ = t - closed >= config_.retention_ticks ? Bits(buffer_.size(), X) :
                              storage.readLogic(first, buffer_.size() / 8);
                    storage.writeLogic(t, first, Bits(buffer_.size(), X)); // Destructive sample.
                } else if (stage_ == 2) storage.writeLogic(t, first, buffer_); // Restore.
                else if (stage_ == 3) {
                    if (op_ == 1) { open_ = true; outputs_["BUSY"] = {L}; }
                    else closed_[row_] = t;
                } else if (stage_ == 5) {
                    refresh_row_ = (refresh_row_ + 1) % (config_.depth_words / config_.words_per_row);
                    outputs_["BUSY"] = {L};
                }
            } else if (op_ == 2) {
                outputs_["READ_DATA"] = Bits(buffer_.begin() + col_ * W, buffer_.begin() + (col_ + 1) * W);
                outputs_["READ_VALID"] = {H}; outputs_["BUSY"] = {L};
            } else if (op_ == 3) {
                if (stage_ == 1) {
                    for (std::size_t b = 0; b < W; ++b)
                        if (mask_[b / 8] == H) buffer_[col_ * W + b] = stored(data_[b]);
                    // Only selected bytes are program writes; row restoration is not.
                    write(t, row_ * config_.words_per_row + col_, data_, mask_);
                } else if (stage_ == 3) outputs_["BUSY"] = {L};
            } else if (op_ == 4) {
                if (stage_ == 1) closed_[row_] = t;
                if (stage_ == 3) { open_ = false; outputs_["BUSY"] = {L}; }
            }
            if (high(outputs_, "BUSY")) due_ = after(t, config_.phase_ticks);
        }
        if (!edge(s)) return;
        auto op = number(signal(s, "CMD", 3)), address = number(signal(s, "ADDR", 32));
        if (!op) return;
        if (high(outputs_, "BUSY")) { outputs_["ERROR"] = {H}; return; }
        outputs_["READ_VALID"] = {L}; outputs_["READ_DATA"] = Bits(W, Z);
        if ((op == 1 && open_) || ((op == 2 || op == 3 || op == 4) && !open_) || (op == 5 && open_)) {
            outputs_["ERROR"] = {H}; return;
        }
        outputs_["ERROR"] = {L}; outputs_["BUSY"] = {H}; op_ = op; stage_ = 0;
        if (op == 1 || op == 5) row_ = op == 1 ? address : refresh_row_;
        if (op == 2 || op == 3) col_ = address;
        if (op == 3) { data_ = signal(s, "WRITE_DATA", W); mask_ = signal(s, "WRITE_MASK", W / 8); }
        due_ = after(t, config_.phase_ticks);
        auto remaining = config_.max_resident_bytes - std::min(config_.max_resident_bytes, storage.allocatedDataBytes());
        if (closed_.size() > remaining / 128) throw std::length_error("DRAM row metadata budget exceeded");
    }
    void flash(std::size_t t, const Signals& s) {
        if (due_ && t >= due_) {
            due_ = 0; ++stage_;
            if (op_ == 1) {
                outputs_["READ_DATA"] = storage.readLogic(address_ * (W / 8), W / 8);
                outputs_["READ_VALID"] = {H}; outputs_["BUSY"] = {L};
            } else if (stage_ == 1) {
                if (op_ == 2) write(t, address_, data_, mask_, true);
                else {
                    auto first = address_ / config_.block_words * config_.block_words;
                    for (auto word = first; word < first + config_.block_words; ++word)
                        storage.writeLogic(t, word * (W / 8), Bits(W, H), true);
                }
                due_ = after(t, config_.phase_ticks);
            } else if (stage_ == 2) due_ = after(t, config_.phase_ticks);
            else outputs_["BUSY"] = {L};
        }
        if (!edge(s)) return;
        auto op = number(signal(s, "CMD", 3));
        if (!op) return;
        outputs_["ERROR"] = {L}; outputs_["READ_VALID"] = {L}; outputs_["READ_DATA"] = Bits(W, Z);
        if (high(outputs_, "BUSY") || ((op == 2 || op == 3) && !enabled_)) {
            outputs_["ERROR"] = {H}; return;
        }
        if (op == 4 || op == 5) { enabled_ = op == 4; return; }
        op_ = op; stage_ = 0; address_ = number(signal(s, "WORD_ADDR", 32));
        data_ = signal(s, "WRITE_DATA", W); mask_ = signal(s, "WRITE_MASK", W / 8);
        if (op != 1) enabled_ = false;
        outputs_["BUSY"] = {H};
        due_ = after(t, op == 1 ? config_.phase_ticks : op == 2 ? config_.program_ticks : config_.erase_ticks);
    }
public:
    MemoryStorage storage; // Storage mechanics only; all device rules are above/below.
    explicit CompactDevice(EndpointConfig c)
        : config_(c), buffer_(W * c.words_per_row, X),
          storage(c.depth_words, W, technology == Technology::ROM ? L : technology == Technology::NORFlash ? H : X,
                  c.record_history, {c.paged, c.max_resident_bytes, c.max_history_bytes}) {
        outputs_["READ_DATA"] = Bits(W, Z);
        for (auto p : {"BUSY", "ERROR", "READ_VALID", "FAULT"}) outputs_[p] = {L};
        if constexpr (technology == Technology::ROM) {
            std::vector<std::uint8_t> image;
            for (std::size_t i = 0; i < c.image_hex.size(); i += 2)
                image.push_back(std::stoul(c.image_hex.substr(i, 2), nullptr, 16));
            storage.loadBytes(0, image);
        }
    }
    Bits read(const std::string& pin, std::size_t width) const { return signal(outputs_, pin, width); }
    std::size_t deadline() const { return due_; }
    void update(std::size_t t, const Signals& s) {
        if constexpr (technology == Technology::FF) {
            bool rising = edge(s); auto word = number(signal(s, "WORD_ADDR", 32));
            if (rising && high(s, "WE")) write(t, word, signal(s, "WRITE_DATA", W), signal(s, "WRITE_MASK", W / 8));
            outputs_["READ_DATA"] = high(s, "READ_EN") ? storage.readLogic(word * (W / 8), W / 8) : Bits(W, L);
        } else if constexpr (technology == Technology::SRAM) {
            if (high(s, "CE_N")) {
                selected_ = false; due_ = 0; outputs_["READ_DATA"] = Bits(W, Z); return;
            }
            if (!selected_) { selected_ = true; latched_ = s; due_ = after(t, 4 * config_.phase_ticks); }
            if (!due_ || t < due_) return;
            due_ = 0; auto word = number(signal(latched_, "WORD_ADDR", 32));
            if (!high(latched_, "WE_N"))
                write(t, word, signal(latched_, "WRITE_DATA", W), signal(latched_, "WRITE_MASK", W / 8));
            else outputs_["READ_DATA"] = storage.readLogic(word * (W / 8), W / 8);
        } else if constexpr (technology == Technology::ROM) {
            outputs_["READ_DATA"] = high(s, "CE_N") || high(s, "OE_N") ? Bits(W, Z) :
                storage.readLogic(number(signal(s, "WORD_ADDR", 32)) * (W / 8), W / 8);
        } else if constexpr (technology == Technology::DRAM) dram(t, s);
        else if constexpr (technology == Technology::NORFlash) flash(t, s);
    }
};

template<std::size_t W, class Model>
class CompactEndpoint {
    EndpointConfig config_;
    Sequence sequence_;
    CompactDevice<W, Model> device_;
    bool pending_ = false, full_ = false;
    Bits held_ = Bits(W,L);
    Status status_ = Status::Ok;
public:
    struct Inputs {
        bool rising_edge=false, reset=false, request_valid=false, response_ready=false;
        Request request{bits(3,0),bits(32,0),Bits(W,L),Bits(W/8,L)};
    };
    struct Outputs {
        bool request_ready=false,response_valid=false;
        Bits read_data=Bits(W,L);
        Status status=Status::Ok;
    };
    explicit CompactEndpoint(EndpointConfig c)
        : config_(c),sequence_(W,Model::technology,c),device_(c) { c.validate(W,Model::technology); }
    const MemoryStorage& storage() const { return device_.storage; }
    Outputs step(std::size_t t,const Inputs& i) {
        constexpr bool fast=Model::technology==Technology::FF;
        const bool room=!full_||i.response_ready;
        const bool complete=pending_&&sequence_.done;
        const bool ready=!i.reset&&room&&(fast||((!pending_||(complete&&i.response_ready))&&sequence_.available));
        const bool accept=ready&&i.request_valid, incoming=fast?accept:complete;
        auto status=fast?sequence_.validate(i.request):sequence_.status;
        Bits data=fast?Bits(W,L):sequence_.result;
        if (fast&&accept&&status==Status::Ok&&number(i.request.op)==0)
            data=device_.storage.readLogic(number(i.request.address),W/8);
        if (i.reset) { pending_=full_=false; held_.assign(W,L); status_=Status::Ok; }
        else if (i.rising_edge) {
            const bool capture=incoming&&room&&(full_||!i.response_ready);
            const bool hold=full_&&!i.response_ready;
            if (capture) { held_=data; status_=status; }
            full_=capture||hold;
            if (!fast) pending_=accept||(pending_&&!(complete&&room));
        }
        if (fast) {
            Signals pins{{"CLK",{L}},{"WORD_ADDR",bits(32,number(i.request.address)/(W/8))},
                {"WE",{accept&&status==Status::Ok&&number(i.request.op)==1?H:L}},
                {"READ_EN",{L}},{"WRITE_DATA",i.request.data},{"WRITE_MASK",i.request.mask}};
            device_.update(t,pins);
            if (i.rising_edge) { pins["CLK"]={H}; device_.update(t,pins); }
        } else {
            device_.update(t,sequence_.outputs);
            sequence_.step(t,i.rising_edge,i.reset,accept,i.request,
                [&](const std::string& pin,std::size_t width){return device_.read(pin,width);},complete&&room);
            device_.update(t,sequence_.outputs);
        }
        const bool room_now=!full_||i.response_ready, complete_now=pending_&&sequence_.done;
        const bool ready_now=!i.reset&&room_now&&(fast||((!pending_||(complete_now&&i.response_ready))&&sequence_.available));
        if (fast) {
            data.assign(W,L);
            if (ready_now&&i.request_valid&&status==Status::Ok&&number(i.request.op)==0)
                data=device_.storage.readLogic(number(i.request.address),W/8);
        } else { data=sequence_.result; status=sequence_.status; }
        return {ready_now,!i.reset&&(full_||(fast?(ready_now&&i.request_valid):complete_now)),
                full_?held_:data,full_?status_:status};
    }
    std::size_t next_event_time() const {
        auto a=sequence_.deadline(),b=device_.deadline();
        return !a?b:!b?a:std::min(a,b);
    }
};

auto make_sram_example() {
    EndpointConfig config;
    config.depth_words = 4096; // 4096 words × 4 bytes = 16 KiB.
    return CompactEndpoint<32, SRAMModel>(config);
}
} // namespace memory_example
```

The example is executed by the documentation test, which checks both children and their connected native pins. Unlike `Controller` above, the returned endpoint owns actual storage. Select its behavioral implementation to replace the controller/device assembly with `BehavioralMemoryEndpoint`; do not substitute a native SRAM device at the transaction pins.

#### Unknown inputs and timing

The endpoint adds no new transaction semantics. Structural and compact implementations agree at documented transaction checkpoints, not at every internal gate transition. Unknown data and error results follow 3.2. Model times are not calibrated hardware performance claims.

### Implementation

#### Structural implementation

Controller on the left, native device on the right. The device retains its existing word/row/column layout and family-specific pins. Native device children may independently select their existing behavioral implementations through the explorer.

#### Behavioral implementation

The five technology endpoints can instead use the fused `BehavioralMemoryEndpoint` leaf. It owns one controller state machine and one compact device model. A `MemoryContainer` is only a native device: it needs its technology controller when attached to transaction pins.

The `memory.<technology>.scalable-endpoint.<width>` contracts default to the fused endpoint. Their structural selection exposes `CONTROLLER` and a compact native `MEMORY`; it never expands a full-size store into individual cells. Thus CPU memory endpoints can be expanded in the explorer without changing capacity or allocating thousands of storage cells. Pre-simulation image provisioning delegates to that same native store. Python exposes this separately as `initialize_memory_bytes(component, byte_address, bytes)`; runtime writes must still use the protocol.

#### Visualization and inspection

The memory table is a read-only view of recorded storage and signal history. Python and WebAssembly use the same inspector. Inspection and timeline scrubbing do not send transactions or advance the device.

| Display | Meaning |
|---------|---------|
| Address and highlighted row | The live offered request, or the accepted request while its response is pending/held |
| `READ`, `WRITE`, `PROGRAM`, `ERASE` | Operation belonging to that request; read is green and modifying operations are orange |
| `READY`, `WAIT`, `PENDING`, `RESPONSE`, `HELD` | Request/response phase; `HELD` means the consumer has not accepted the response |
| Accepted time, write data, byte mask | Original accepted payload, not later values on request pins |
| Device phase and maintenance | Recorded native sequencing activity, including automatic refresh; not an extra controller |
| Instruction text | RV32I disassembly for an instruction-memory endpoint and its nested native device |

Internal activity timestamps are included in the visualizer timeline even when
the endpoint's external bus has not changed. Only signals belonging to that
technology's native interface are listed. This observation history adds no
simulated registers, events, or memory latency.

The observer samples handshake and payload signals **before the rising edge**, as required by the synchronous interface. It handles a request and response completing on the same edge without inventing a pending cycle. For a delayed response, later changes to `REQ_ADDR`, `REQ_OP`, or write data do not change the displayed accepted request. Reset drops that transaction context, not the stored image. In a CPU instruction memory, the highlight identifies the **fetch address**, not the retired instruction or every occupied pipeline stage.

`Follow access` centers the table on the active word. Manual row scrolling suspends centering. The inspector's byte-address field, `Previous page`, and `Next page` browse the entire device; they read history directly without performing a hardware read. Address pages contain at most 256 words per request (64 by default). The sparse touched-word summary is limited to 256 entries, but this does **not** limit address browsing. Unknown/unwritten values remain visible according to the device's storage model.
