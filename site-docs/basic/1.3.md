# § 1.3. Logic Gates

The logic gates are the leaves every structural circuit ends in. Each one-bit
gate is a leaf part: it has no children, computes its output from its inputs
with the four-state rule of its kind, and publishes it one gate delay later
([§ 1.2 Gates](1.2.md#gates)). The word gates apply a one-bit gate to every
bit of a word, so a recipe that treats a word bit by bit can use one part per
word.

| Component | Description | Structural | Behavioral |
| --- | --- | :---: | :---: |
| `NOTGate` | Inverts one bit | Yes | No |
| `ANDGate` | 1 when both inputs are 1 | Yes | No |
| `ORGate` | 1 when either input is 1 | Yes | No |
| `NANDGate` | 0 only when both inputs are 1 | Yes | No |
| `NORGate` | 1 only when both inputs are 0 | Yes | No |
| `XORGate` | 1 when the inputs differ | Yes | No |
| `ANDGate<W>` | One gate of a kind on every bit of a W-bit word; also `NANDGate<W>`, `ORGate<W>`, `NORGate<W>`, `XORGate<W>` and `NOTGate<W>` | Yes | Yes |

A one-bit gate's "structural" form is the gate itself: a leaf with no smaller
parts and no separate compact form. There is no one-bit XNOR gate; circuits
build it as an XOR followed by a NOT.

## 1.3.1. `NOTGate`

`NOTGate` inverts one bit.

### IO pins

| Pin | Direction | Width | Description |
| --- | --- | ---: | --- |
| `IN` | Input | 1 | Operand bit |
| `OUT` | Output | 1 | Result bit |

### Behavior

For binary inputs,

$$
\mathrm{OUT} = \lnot \mathrm{IN}.
$$

A rising input gives a falling output one gate delay later; in the realistic profiles the inverter is the fastest gate (one FO4 delay).

#### C++ example

```cpp
bool not_gate_ref(bool in) { return !in; }
```

This binary function describes the settled output. It is not a registered implementation.

#### Unknown inputs

`X` and `Z` both give `X`; the output never drives `Z`.

| `IN` | Settled `OUT` |
| --- | --- |
| 0 | 1 |
| 1 | 0 |
| `X` or `Z` | `X` |

### Implementation

#### Structural implementation

`NOTGate` is a leaf: `evaluate()` reads the input, applies the four-state rule above and schedules the output one gate delay later. The delay is inertial: an input change that is undone before the output is published withdraws the pending output. The gate has no children, no state and no compact form; parts that need NOT on whole words use [`NOTGate<W>`](#137-andgatew).

## 1.3.2. `ANDGate`

`ANDGate` 1 when both inputs are 1.

### IO pins

| Pin | Direction | Width | Description |
| --- | --- | ---: | --- |
| `A` | Input | 1 | First operand bit |
| `B` | Input | 1 | Second operand bit |
| `OUT` | Output | 1 | Result bit |

### Behavior

For binary inputs,

$$
\mathrm{OUT} = A \land B.
$$

In the realistic profiles AND is a NAND followed by an inverter.

#### C++ example

## 1.3.7. `ANDGate<W>`

`ANDGate<W>` applies the one-bit AND to every bit of two W-bit words. Its
siblings `NANDGate<W>`, `ORGate<W>`, `NORGate<W>`, `XORGate<W>` and
`NOTGate<W>` do the same with their one-bit gate; this section describes all
six, with `ANDGate<W>` as the recorded example. W is any width from 2 to 32.
Each width and kind is its own contract, `logic.<kind>.<W>` (for example
`logic.and.8`, `logic.not.32`), returned by `circuit::word::gate(GateKind, W)`.

### IO pins

| Pin | Direction | Width | Description |
| --- | --- | ---: | --- |
| `A` | Input | W | First operand word (`IN` for `NOTGate<W>`) |
| `B` | Input | W | Second operand word (absent for `NOTGate<W>`) |
| `OUT` | Output | W | Bit i is the gate of bit i of the inputs |

### Behavior

For binary inputs, bit i of `OUT` is the one-bit gate of bit i of `A` and
`B`:

$$
\mathrm{OUT}_i = A_i \land B_i \qquad (0 \le i < W).
$$

The bits are independent: nothing carries from one bit to the next. A recipe
that applies the same gate to every bit of a word, or masks a word with one
enable bit spread across it by wiring, uses one word gate instead of W
separate gates; the gates and their timing are the same.

#### C++ example

```cpp
#include <cstdint>

uint32_t and_word_ref(uint32_t a, uint32_t b, unsigned width) {
    const uint32_t mask = width >= 32 ? ~0u : (1u << width) - 1;
    return (a & b) & mask;
}
```

This binary function describes the settled output. It is not a registered implementation.

#### Unknown inputs

Each bit follows its one-bit gate's rule: for `ANDGate<W>`, a 0 in either
input bit gives 0, two 1s give 1, and anything else gives `X`. One bit's
unknown value does not affect the other bits. The output never drives `Z`.

### Implementation

#### Structural implementation

W one-bit gates `AND_0` … `AND_<W−1>` between zero-delay wiring parts: the
`Rewire`s `A_BITS` and `B_BITS` (`IN_BITS` for `NOTGate<W>`) split the
inputs into bits, and `OUT_WORD` joins the gates' outputs. Each bit's path
is one gate, exactly as in a bit-by-bit circuit. In the simulator a closed
word gate is drawn as its one-bit symbol with its width (for example `/8`);
opening it shows the W gates.

#### Behavioral implementation

One leaf evaluates the whole word at once with the same per-bit rule on the
packed value, and publishes it on the delays proven on the W gates
([§ 1.2 Compact parts](1.2.md#compact-parts)). Like every compact part it uses
transport delay, so a pulse shorter than one gate delay, which the inertial
one-bit gates swallow, can still reach `OUT`.
